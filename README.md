# Ubuntu Linux on VirtualBox (Systems & Operations Lab)

This repository documents hands-on labs and exercises using Ubuntu Linux
deployed on VirtualBox to build foundational skills in Linux administration,
system operations, networking, and security within a controlled lab
environment.

The focus is on developing practical Linux skills that support CloudOps,
DevOps, and infrastructure engineering roles.

---

## Lab Environment

- Ubuntu Server & Ubuntu Desktop
- Oracle VirtualBox
- Isolated virtual networking (NAT / Host-Only / Internal Network)
- Snapshot-based lab workflows

All activities are performed in a non-production, local lab environment.

---

## Tools & Technologies Used

- Ubuntu Linux
- Bash & Shell Scripting
- systemd
- apt & package management
- OpenSSH
- UFW (Uncomplicated Firewall)
- Netplan
- cron
- VirtualBox Networking

---

## Linux & Operations Concepts Covered

- Linux installation and system configuration
- User and group management
- File system structure and permissions
- Process and service management
- Network configuration and troubleshooting
- Secure remote access using SSH
- Firewall configuration and host hardening
- System monitoring and log analysis
- Task scheduling and automation

---

## Featured Labs & Exercises

- Ubuntu installation and VirtualBox configuration
- User, group, and sudo management
- SSH key-based authentication setup
- Firewall configuration with UFW
- Network configuration using Netplan
- Service management with systemctl
- Log review and troubleshooting
- Bash scripting for administrative tasks
- System update and patching workflows
